# The Weeknd

## Опис проєкту

Music Legends Hub - це односторінковий сайт, присвячений творчості та кар’єрі The Weeknd. Проєкт містить кілька тематичних секцій: головний екран, біографію, дискографію, блок про акторський дебют, нагороди, форму підписки та футер з контактною інформацією.

Макет сайту був створений мною самостійно у Figma у якості дипломної роботи з курсу UI&UX.

[Посилання на макет у Figma](https://www.figma.com/design/tKzOErKtxSOB8U2GNcX2CF/Untitled?node-id=0-1&t=nvrBbiznVuYgBqE1-1)

## Використані технології

* HTML5
* SCSS / CSS3
* JavaScript
* Flexbox
* CSS Grid
* CSS-анімації та transitions
* Робота з псевдоелементами `::before` та `::after`

## Основний функціонал

* Секція з біографією артиста
* Інтерактивна секція дискографії
* Карусель альбомів на JavaScript
* Timeline-блок з нагородами
* Hover-ефекти для елементів таймлайна
* Форма підписки
* Футер із контактами та соціальними мережами

## Особливості реалізації

У проєкті активно використовувалися CSS Grid та Flexbox для побудови складних секцій. Декоративні елементи, такі як фонові написи, кола, лінії таймлайна та точки, реалізовані через позиціонування, `z-index` і псевдоелементи.

Для секції дискографії була реалізована карусель на JavaScript. Вона дозволяє перемикати альбоми, змінювати активний елемент і плавно пересувати слайди.

Під час роботи над проєктом я використовувала допомогу ШІ, зокрема для пояснення складних моментів верстки, роботи з CSS Grid/Flexbox, псевдоелементами, а також для допомоги з JavaScript-логікою каруселі.
